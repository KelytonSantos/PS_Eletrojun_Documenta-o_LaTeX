\section{Introdução}

% Descreva o contexto e a motivação do projeto.
% O que é o sistema? Por que ele foi desenvolvido? Qual problema resolve?

Este documento descreve o desenvolvimento de um sistema de monitoramento ambiental
baseado em microcontrolador, capaz de coletar dados de temperatura e umidade do ambiente
e disponibilizá-los em tempo real por meio de uma interface web.

O projeto foi desenvolvido como parte do processo seletivo da Eletronjun e contempla tanto aspectos de eletrônica quanto de software (firmware
do microcontrolador e interface web de controle).

A solução permite ao usuário monitorar as condições ambientais remotamente, alternar
entre modos de operação do sistema (Desligado, Ligado e Automático) diretamente
pela interface web, e observar o estado atual do sistema por meio de LEDs indicadores
presentes no hardware.
